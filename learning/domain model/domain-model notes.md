notes:

    ERDs:

        Database: collects information thats organised for easy: storage, management, updates and retrieval

        ERDs provide a visual way to understand how info is related.

        Entity: an object tracked in the database

        Attributes: Properties or traits of entities. e.g: entity "customer" can have attributes: "last name", "city"

        entities are always rows and attributes are always columns

        Relationship: Describes how entities interact with each other.

        Cardinalities: Help define relationship in a numerical context (one to many, many to many, one to one etc)

    Cucumber BDD:

        Scenario
        Given: already exists before action
        When: what user does
        Then: output to user

        Gherkin is a set of grammar rules that makes plain text structured enough for cucumber to understand.

        Step defintions connect gherkin to programming code. A step defintion carries out the action that should be performed by the step.
